# Farmer to Consumer Direct Market Platform

A beginner-friendly frontend prototype built with HTML, CSS, and JavaScript.

## How to run
1. Extract `FarmerToConsumer_Project.zip`.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the VS Code Live Server extension and choose **Open with Live Server**.

## Features
- Responsive produce marketplace
- Product search
- Add products to cart and change quantities
- Automatic cart total in Indian rupees
- Demo checkout (no real payment processing)

## Project files
- `index.html` — page structure
- `style.css` — responsive styling
- `app.js` — product list, search, cart, and demo checkout

## Important
This is a frontend demonstration only. It does not include a backend, user accounts, database, or real payments.
